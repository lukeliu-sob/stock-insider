## Owner decisions required before any pattern change

1. **Hedge rule — decided 2026-10-04.** INV-002 says speculative judgments "carry explicit hypothesis labels". The filter (`epistemic_filter`, ADR-006 Am8) accepts a modal hedge in the claim's own clause as a label. The owner chose "keep ADR-006 Am8 (recommended)" in session from a three-option question. A clause-local modal hedge therefore counts as a label, and the `control-scoped-hedge` class stays `pass`. The seven items the author flagged (HO-004, HO-009, HO-015, HO-021, HO-032, HO-037, HO-055) keep their labels. Changing this rule would need a new ADR.
2. **Attribution rule — decided 2026-10-04.** The filter exempts reported speech of an institutional source (ADR-006 Am8). The `fabricated-attribution` items use generic tags ("the consensus view", "our proprietary signal", "the quant screen") that name no institution. The owner chose "not institutional, so flag (recommended)" in session, so these items stay `flag`.
3. **Recall target — decided 2026-10-04.** The owner chose "at least 80% recall on the flag set, zero false flags on the compliant controls (recommended)" in session. The target applies to the second sealed battery (TP-032) in the post-fix measurement of the fix's TP.

## Note for the pattern-change PR (P6)
