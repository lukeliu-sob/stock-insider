## Scope

Make EODHD News the primary symbol-scoped source; GDELT remains the
macro-group track (its 3-month global window is the macro value;
its throttle penalty is the reason it cannot be the primary).

- `src/stockinsider/data/ingest/eodnews.py`:
  - `EodhdNewsAdapter` on the existing classified transport seam
    (`EODHD_API_KEY`; one request per symbol per run; `limit`
    bounded; failures classified http/throttle/transport as in
    BD-013's taxonomy — EODHD returns JSON bodies for errors, and
    402 keeps the capacity-is-bought single-shot semantics).
  - `run_eodhd_news_sync`: after the GDELT track inside the same
    news track run (isolated per-source), fetch per active
    watchlist symbol; store through the S1–S4 machinery with one
    evidence refinement: an exact canonical-symbol hit in the
    item's `symbols` list is +1 token evidence (the vendor did the
    entity resolution — stronger than our token heuristics);
    official-name/alias/ticker logic unchanged as the fallback.
  - S1 adaptation for the EODHD item shape: `date` (ISO 8601)
    parses and gates the window; language assumed English
    (vendor-stated; recorded here — no silent guessing at runtime).
- Schema migration v5: `news` gains `content TEXT`, `sentiment TEXT`
  (JSON as returned — stored verbatim as vendor evidence, never
  merged into scoring), and `source TEXT NOT NULL DEFAULT 'gdelt'`;
  `news_quarantine` gains `source`. Cross-source dedup comes free
  through the existing Key A (normalized URL) and Key B (title
  token Jaccard).
- Status: `news_status` reports per-source counts.
- Embedding remains title-only and deferred (owner decision
  pending); content is stored now so the corpus is ready.

Out of scope: keyword/macro search via EODHD (GDELT keeps macro),
sentiment-based scoring (FR-009 contrast analysis is a later,
explicitly planned step), body-aware retrieval (needs embeddings).
