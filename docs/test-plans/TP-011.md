## Scope

Build the news corpus path end to end under the accepted design:

**011a — pure filter core + labeled fixture corpus (no network)**

- `src/stockinsider/data/ingest/newsfilter.py`:
  - S1 structural gates: `language` English (case-insensitive — live evidence:
    GDELT emits the full word "English"), `seendate` parseable
    (`yyyyMMddTHHmmssZ`, live-verified format), published within the cursor
    window, URL parses with http(s) scheme (live evidence: `http://` is
    common), domain not on the blocklist. Any failure produces a structured
    quarantine record carrying the failing gate — never a silent drop.
  - S2 relevance scoring, pure functions: `token_evidence` (mandatory ≥ 1:
    +1 exact ticker token word-boundary case-sensitive; +1 official-name
    exact phrase; +0.5 normalized alias containment — normalization must
    absorb GDELT's spaced punctuation, live evidence: titles arrive as
    "closes 1 . 18 pct higher"), `source_tier` (+1.0 tier-A per D2; +0.3
    general-news domain; 0 unknown), `negative_signals` (−1 promotional
    phrase blocklist; −1 aggregator/parked patterns). Keep rule:
    `token_evidence >= 1 AND score >= 1.0` (τ per D2).
  - S3 deduplication keys: Key A normalized URL (strip `utm_*` params,
    mobile/desktop host canonicalization, trailing slash, scheme); Key B
    normalized-title token set with Jaccard ≥ 0.8 within the same bucket
    (symbol or macro group) within 14 days; survivor rule
    `(source_tier, earliest seendate)` total order.
- `test/offline/fixtures/news_corpus_v1.json`: ~200 hand-labeled headlines
  (AI-drafted, owner-reviewed; append-only once merged) with class tags:
  positive, alias-only, same-name-different-entity, ticker-collision
  (bare "700", single-letter tickers), macro-only, promotional spam,
  quarantine variants (non-English, unparseable date, out-of-window URL
  forms, blocklist domain).
- Precision gate: keep-decision precision ≥ 0.8 over the fixture corpus
  (recall recorded, not gated; both reported to the evaluation logbook as
  QA-002 evidence).

**011b — transport + storage + sync integration**

- `src/stockinsider/data/ingest/news.py`: S0 query construction (one query
  per active watchlist symbol from the symbol map; one per macro keyword
  group per D4), GDELT DOC 2.0 calls through the classified transport,
  failure taxonomy (HTTP error / malformed JSON / throttle-429) with
  explicit per-track failure reports and transactional per-batch writes.
- Schema migration v4: `news_articles` (bucket = canonical symbol or macro
  group, url_norm + url_raw, domain, title_raw, seendate, language,
  sourcecountry, relevance_score + breakdown JSON, keep decision, query
  provenance, produced_at/fetched_at), `news_quarantine` (failing gate,
  raw evidence, query provenance), `sync_state` news-track cursor.
- S5 retention: articles older than 2 years deleted (v1: whole row);
  event-score snapshots (TP-013+) retain headline + URL + score
  indefinitely per memory-design §2.
- Sync orchestration: news track runs after the market track in `sync`,
  track-level failure isolation, ≥ 5 s inter-query sleep (live evidence:
  bursts earn 429s with cooldowns exceeding 4 minutes), per-symbol
  ok/failed/throttled reporting surfaced via `sync.status`.
- Live smoke `test/live/test_news_smoke.py`: gated on `GDELT_SMOKE=1`,
  never blocking; confirms empty-result body shape and the `domain:`
  operator (deferred live facts).
- Egress whitelist addition `api.gdeltproject.org` (`shared/egress.py`,
  safety-critical path — proposals protocol, owner approval on the 011b PR;
  SEC-003 by-design evidence recorded).

Out of scope: embeddings/vector retrieval/sanitization helper (TP-012);
LLM event scoring (TP-013+); body fetching (v2, post-QA-002, explicit
owner activation); any LLM participation in filtering (design §1).

## Vendor live-probe evidence (2026-09-21, pre-plan)

- Host `api.gdeltproject.org/api/v2/doc/doc` live; artlist JSON verified.
- Item fields: `url`, `url_mobile`, `title`, `seendate`, `socialimage`,
  `domain`, `language`, `sourcecountry`.
- `seendate` format `20260921T101500Z`; `language` emits the full word
  "English"; `http://` scheme URLs are common; `url_mobile` frequently
  empty string.
- Titles carry spaced punctuation ("closes 1 . 18 pct higher") — alias and
  ticker normalization must absorb this (fixture class included).
- Without `sourcelang:english`, non-English articles leak into results —
  the S1 language gate is a real backstop, not decoration.
- Throttle: two quick probes → 429 (no Retry-After); cooldown exceeded
  4 minutes before recovery. Pacing design (5 s sleep, explicit throttle
  failure, no retry hammering) is mandatory, verified necessary.
- Unverified live (deferred to 011b smoke): empty-result body shape
  (S4 treats missing `articles` key and `[]` identically), `domain:`
  operator behavior.
