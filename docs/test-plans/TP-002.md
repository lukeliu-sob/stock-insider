## Negative tests (mandatory, R7)

Eleven negative/adversarial tests above. Headline adversarial intent: nothing pretends success — artifact/snapshot overwrite attempts, phantom index rows, unknown sessions, invalid profiles, mid-session profile switches, unknown slash commands, unimplemented commands, and free-text turns all fail loudly with English messages naming the governing requirement.

## Boundary cases (R8, for threshold rules)

Budget envelopes at bound and bound ±1: quick 29,999/30,000/30,001; standard 99,999/100,000/100,001; deep 399,999/400,000/400,001 (bound inclusive; one token over aborts).

## Fit-criteria mapping

- **FR-011**: layout test asserts the full tree; append-only test asserts byte-prefix invariance; artifact/snapshot refusal tests assert the never-overwrite clause; index phantom test asserts index integrity (S1 evidence).
- **FR-012**: seeded listing asserts exact filter matches and zero phantom output; empty result is explicit ("no sessions match the filter"), exit 0.
- **FR-020**: differing-profiles test asserts both the record field and the envelope; boundary matrix asserts the inclusive bound; switch refusal asserts the fixed-for-lifetime clause.
- **FR-013 (REPL half)**: bare invocation and analyze tests assert REPL entry/exit; slash tests assert dispatch; free-text negative asserts the explicit-failure contract. The `--help` surface test from TP-001 continues to cover the subcommand half.
