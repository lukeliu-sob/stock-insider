## Scope

Close the retrieval loop: the embedded corpus becomes searchable, and
retrieved headlines reach the model through the sanitizer — the first
SEC-002 enforcement point in the live path.

**012a — sanitizer (safety-critical, proposals protocol) + embedding storage**

- `src/stockinsider/shared/sanitize.py` (owner approval required:
  safety-critical path): layer-one neutralization for untrusted
  headlines. Control characters stripped; instruction-like patterns
  (`ignore previous`, `system:`, `disregard`, fake-tool-output
  fragments, `AI:`/`assistant:` role markers) replaced with inert
  markers; the transformation is total and deterministic (same input,
  same output, no config). Storage keeps raw text (evidence); only the
  egress path into model context sanitizes.
- `src/stockinsider/data/store/vector.py`: vec0 virtual table
  (`vec_news(embedding float[N])`) in the same SQLite file, guarded by
  extension availability; vectors carry `news_id`, `model_id`,
  `embedded_at`; the model-ID rule is enforced — insertions with a
  model_id differing from the table's registered model are refused,
  and a mismatch on query fails closed with the explicit
  rebuild-required error (memory-design §2.3).
- Embedding pipeline `src/stockinsider/data/ingest/embed.py`: embed
  pending `news` rows (title only, v1 title corpus) through the
  provider `embed()` wire; batched; failures explicit per batch,
  nothing half-written; idempotent (rows with vectors are skipped).
  Offline tests never call the provider (injected embedding function).

**012b — registry tool + quality gates**

- Registry `news.search` (READ): query text -> embedding -> KNN over
  `vec_news` joined to `news` (bucket filter optional), top-k (default
  5), **sanitize on egress**, structured result (title-sanitized,
  url, domain, seendate, bucket, similarity) — the only news source
  the agent may cite (FR-007). Tool result enters the INV-001 pool
  like every other numeric-bearing payload.
- CLI: no new surface (retrieval is agent-side); `sync` unchanged
  (embedding backfill is a separate explicit command or runs
  post-sync behind a flag — decision recorded at implementation).
- FR-007 quality gate: fixture corpus of ~20 known-target questions;
  target in top-5 for >= 80 percent. Offline: deterministic
  pseudo-embeddings (seeded token hashing) prove KNN mechanics,
  bucket filters, and the model-ID refusal. Live/eval: the same
  question set against the real embedding model (never blocking;
  reported to the evaluation logbook as QA-002 evidence).
- SEC-002 adversarial suite `test/offline/test_injection_suite.py`:
  injection-payload corpus (prompt override, fake tool output, role
  spoofing, unicode-obfuscated directives); assertions: sanitizer
  output contains no active directive forms; the `news.search` tool
  result carries sanitized text only; raw storage remains untouched.

Out of scope: event scoring (TP-013+, FR-009), report composition
(FR-008, TP-013), hybrid keyword retrieval (v1 vector-only per
FR-007 tradeoff), re-ranking.

  an in-memory probe (top-1 exact match, distance 0.0).

  (`deepseek-flash` embedding default; stateless calls only).
