## Driver

The test ran every CLI command on a copy of the real store: `watch add`, `sync`, `embed`, `info`, `digest`, a four-turn `analyze` session with real model calls, `sessions`, `show` and `resume`. The owner's `data/` was not written. Three defects were found:

| # | Defect | Cause |
|---|---|---|
| 1 | Once a store holds vectors, every `embed` run exits 1 with `UNIQUE constraint failed on vec_news primary key`. "pending before" always reads 128. | `pending_news` queries `vec_news` before sqlite-vec is loaded on the connection. The "no such module: vec0" error is caught as if the table were missing, so the first 128 rows come back as pending, already-embedded rows included. The first batch then collides. |
| 2 | `watch add aapl.us` stores the name "AAPL.US (name unverified - vendor search does not index this exchange; verify before adding)". | `watch add` sends every symbol-shaped query to direct verification (BD-017). That path exists because vendor search does not index HK listings. US listings are indexed, so the placeholder and its stated reason are both wrong there. |
| 3a | In a comparison table `\| Window \| Tencent \| Hang Seng \|`, every correct value in the Tencent column is flagged "this price change belongs to 0700.HK". | `symbol.search "Tencent"` returned 16 listings named "Tencent ...", so the name word is ambiguous and dropped from the name map. The column header then names nothing, and the subject falls back to the last mention in the paragraph: "Hang" in the other column's header. |
| 3b | "a session range of 391.8 to 402.6" and "range 70.45–73.20" are flagged "quoted for a different field". | TP-045's range rule reads only a pair written before "range". A pair after "range", or joined by "to", is not read as low and high. |
| 3c | "the 60- and 250-session windows" flags 60 as a drawdown. | A suspended hyphen ("60-") is not read as a count. |

3a also leads the model astray. The flag feedback made it tell the user to "disregard" correct numbers, and it raised the three-in-a-row warning.

## Scope

1. `data/store/vector.py`:
   - `pending_news` loads the extension first. It falls back to "every row is pending" only when `vec_news` does not exist in `sqlite_master`. If the extension cannot load, it raises `VectorUnavailable` (INV-003).
   - A new `pending_count` gives the true backlog size.
   - `data/ingest/embed.py` reports `pending_before` from `pending_count`.
2. `cli/app.py` `watch add`:
   - a symbol-shaped query whose exchange is not HK goes to vendor search first. An exact canonical match is used with its official name.
   - with no exact match, it falls back to direct verification.
   - HK queries keep the direct path (BD-017).
   - the INV-004 confirmation is unchanged.
3. `agent/guardrail_claims.py` (claim side; ADR-008 Am5):
   - **ledger_name**: when a name word maps to several symbols, it names the one symbol that a non-search tool returned data for, if there is exactly one.
   - **range_after**: "range [of|from|:] A–B" and "range [of|from] A to B" read A as the low and B as the high (en dash, em dash or "to"; a hyphen-minus stays a sign).
   - **suspended_hyphen**: "60- and 250-session" makes 60 a session count.

Not changed, accepted as residuals:
- "Two symbol issues" (a number word before a noun used as an adjective);
- "5+ revenue periods";
- the date shorthand "2026-11-02/03";
- a "respectively" sentence whose subjects are in the previous sentence;
- "-31.2249% over 250" without "sessions".

"1.8x" (the model's own ratio) was a correct flag.
