## Scope

Close the analysis loop: every indicator the report needs becomes a
deterministic compute function, and the in-session analysis report
becomes an explicit, stored, post-check-gated artifact.

**013a — deterministic indicator suite (data/compute, zero LLM)**

- `src/stockinsider/data/compute/indicators.py` (pure functions,
  golden fixtures at 1e-6):
  - **valuation**: `pe_ratio`, `pb_ratio`, `ps_ratio` — price over
    per-share fundamentals; explicit "unavailable" (None + reason)
    when the feed lacks the field (INV-003, no zero substitution).
  - **profitability**: `roe`, `net_margin`, `gross_margin` from the
    latest fundamentals; TTM where quarterly data allows.
  - **growth**: `yoy_growth` over the stored quarterly series
    (revenue, net income) with explicit coverage gaps.
  - **risk**: `annualized_volatility` (std of daily log returns,
    sqrt 252), `max_drawdown` (peak-to-trough on close), `sharpe`
    only when a risk-free input is explicitly provided.
  - All inputs are stored bars/fundamentals rows; every output
    carries its data window (from/until dates) for provenance.
- Registry `market.indicators` (READ): symbol -> one structured
  snapshot combining the suite (each field: value, unit, window,
  data date, or explicit unavailable line). Enters the INV-001
  pool like every numeric-bearing tool result.
- Structural gate: the existing static arithmetic check already
  confines market-data arithmetic to `data/compute` (FR-006 (a));
  the suite lives inside it — no new enforcement point.

**013b — report command and the FR-008 gate**

- REPL `/report <symbol>`: composes an analysis-instruction turn
  (identity v3 + explicit report schema guidance) over the stored
  facts; the engine's existing post-check runs as always.
- Report persistence: a passing response is stored as a per-turn
  artifact (`report.md` in the session directory) with the
  provenance snapshot reference; a failing response degrades per
  INV-001 and NOTHING is stored as a report.
- `test/offline/test_report_gate.py` (FR-008 regression scope):
  report with untraceable numerics -> degraded, not stored, not
  displayed as-is; report with fully traceable numerics -> stored
  with snapshot reference; provider unavailable -> explicit error,
  no silent fallback.

Out of scope: event scoring (FR-009, needs news corpus + embedding
decision), digest (Should-tier), any LLM arithmetic (never).
