## Driver

The fifth external review (2026-09-30, main `df17550` = PR #54) verified
TP-018/TP-018b and found that the remediation itself introduced two
high-severity bypasses, plus defects that the live run exposed:

| # | Finding (severity) | Origin |
|---|---|---|
| F1 | INV-001: `_ID_CODE` blanks any 1-3 letters glued to 1-4 digits, so "closed at HKD777", "USD1200", "PE35", "RMB500", "YTD-12%" pass unchecked (high) | TP-018b |
| F2 | SEC-003: the loopback exception is `host.startswith("127.")`; `http://127.attacker.example` passes both the HTTPS rule and the whitelist (high) | TP-018b |
| F3 | INV-002 regeneration sends only the stripped draft as a USER message (no identity, no question, no tool results); live: "Looks like that was my previous answer pasted back..." shown as the answer; no trace of the original in session.jsonl (medium) | pre-existing |
| F4 | `HISTORY_WINDOW = 20` counts EVENTS (tool calls included): the model sees about 3 turns and the window can start mid-turn; live: the model denied having stated a close it gave in turn 1 (medium) | pre-existing |
| F5 | INV-002 exemptions launder predictions: any inference verb (suggests/indicates) + any generic noun (company/report) anywhere in the sentence; hedges are sentence-wide and case-insensitive ("In May the stock will rise" passes) (medium) | TP-018b + pre-existing |
| F6 | sync: an empty backfill/incremental reports `ok · 0 bars stored; data through <today>` and advances the cursor; with detection clipped to the earliest stored bar, missing history can become permanently invisible (medium) | TP-018b |
| F7 | sync: benchmark indices are backfilled once and never refreshed, so the calendar freezes and gap detection is blind after the first backfill — REQ-SI-FR-001 requires daily index ingestion (medium) | pre-existing |
