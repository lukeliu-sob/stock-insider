## Driver

FR-016 (Should): "A command generates a weekly digest per watchlist symbol summarizing the week's price action, notable scored events, and upcoming catalysts (earnings dates), rendered from deterministic data with LLM narration under the same REQ-SI-INV-001 gate." Fit criterion: "Scripted digest generation on seeded week data produces a digest whose numerics all pass post-check; missing-data sections render explicit unavailable placeholders rather than being silently omitted." The command has been a stub since TP-003.

## Scope

- New module `agent/digest.py`, behind the agent facade the CLI already uses. `run_digest(store, data_store, ...)` does the following:
  1. Opens a session with the provenance stamp, as the REPL does (GOV-005).
  2. Reads the watchlist through `watchlist.list`. An empty watchlist is an explicit "nothing to digest" with exit 0.
  3. For each symbol, gathers facts only through registry tools (`market.quote`, `market.performance`, `news.recent`), so the data side is reached through the registry alone (AGENTS.md section 6). Each call and result is appended to the session log. The results are stored as the symbol's context snapshot (values-as-seen), which replay reads.
  4. Renders the deterministic sections from those results:
     - **Price action**: the 5-session window's dates, both closes and the change, plus the latest bar's date and close.
     - **Headlines this week**: titles from `news.recent` dated within the window, quoted.
     - **Scored events**: an explicit unavailable placeholder, because event scoring (FR-009) is not implemented.
     - **Upcoming catalysts**: an explicit unavailable placeholder, because no earnings calendar is ingested.
     
     A tool failure renders that section as unavailable, with the tool's error (INV-003).
  5. Runs the rendered text through `guardrail.postcheck_numbers` against the symbol's snapshot. That is the INV-001 gate on the deterministic text itself; a failure marks the numbers, as everywhere else (ADR-008).
  6. When the chat provider is configured, runs one narration turn per symbol through the existing turn engine, with its post-check, markers and reliability notice. Otherwise the narration is an explicit "unavailable: provider unconfigured" placeholder, and the deterministic digest is still complete.
  7. Writes the digest as a session artifact (`digest-<as_of>.md`), never overwritten, and prints it.
- `cli/app.py`: `digest` calls `run_digest` in place of the stub. It exits 1 when any symbol's price section is unavailable, as `sync` does for failed items.
- Not changed: `shared/`, `agent/registry.py`, `agent/guardrail*`, `prompts/` (the narration instruction is a user-turn text, as `/report`'s is), the data side.

## Planned tests

New file `test/offline/test_weekly_digest.py` (the path FR-016's `regression_scope` names).

| Test | Verifies | Kind |
|---|---|---|
| `test_digest_sections_on_seeded_week` | two watchlist symbols with seeded bars and news: each section is present; the price numbers equal the tool results | positive |
| `test_digest_numerics_pass_postcheck` | the fit criterion: every number in the deterministic digest verifies against its snapshot | positive |
| `test_missing_sections_are_explicit_placeholders` | a symbol with no news, and the always-absent events and catalysts, render "unavailable: <reason>" | negative |
| `test_symbol_without_bars_fails_visibly` | a watchlist symbol with no bars renders its price section unavailable with the no-data error, and the CLI exits 1 | negative/adversarial |
| `test_empty_watchlist_is_explicit` | "watchlist is empty; nothing to digest", exit 0, no artifact | negative |
| `test_digest_is_a_replayable_session` | the session log holds the tool calls, the snapshot holds the results, and `show` renders the session with the digest artifact | positive |
| `test_narration_runs_through_the_engine` | with a fake provider, the narration turn runs, is post-checked (a wrong number in it is marked `[?]`), and lands in the artifact | positive + negative |
| `test_cli_digest_without_provider` | the CLI renders the deterministic digest with the narration placeholder and exits 0 | positive |

Mutation checks: drop the post-check of the deterministic text; drop the events placeholder; let a failed tool section disappear instead of rendering unavailable.
