## Negative tests (mandatory, R7)

Ten negative/adversarial tests above. Headline intents: secrets never enter config.json (refused at the API, verified end-to-end via the CLI path); the full key is never rendered; unconfigured endpoints and missing keys are explicit refusals, never guesses; malformed configuration is rejected, never partially applied.

## Boundary cases (R8, for threshold rules)

The QA-001 threshold (0.6) is exercised at its boundary by construction: 6 scored evaluations per replay → passing 4/6 = 0.67 blocks nothing, 3/6 = 0.50 blocks; the exact-boundary case 0.6 (impossible with 6 items) is documented here rather than tested. Budget overrides keep the TP-002 ±1 matrix valid post-override (override applies before envelope queries).

## Fit-criteria mapping

- **FR-021**: layering tests assert both override layers and their precedence; mocked-endpoint test (fit criterion) is the mocked-factory test — configuration selects the endpoint with zero code changes.
- **GOV-005**: stamps tests assert non-placeholder resolved values and zero missing fields across sessions (fit criterion verbatim).
- **QA-001 (seed)**: the live replay is the gate body; threshold math identical to the registry criterion.
- **SEC-001**: secret-refusal + masking + .env-flow tests; the secret-scan gate itself now fails only on tracked .env (CI semantics unchanged).
- **COST-001**: budget override roundtrip + precedence over defaults.
