## Negative tests (mandatory, R7)

Ten negative/adversarial tests. Headline intents: nothing executes without passing the membrane; nothing partial ever escapes a failing handler; write effects never run through the user channel; every failure names its cause.

## Boundary cases (R8, for threshold rules)

None — no numeric thresholds introduced. (The bool-as-int boundary is the type-system analogue of a ±1 case and is covered explicitly.)

## Fit-criteria mapping

- **INV-003**: the fail-closed matrix — unknown/schema/exception/gate — each stage produces an explicit, named failure; no silent fallbacks anywhere in the execution envelope.
- **INV-001 (groundwork)**: the provenance triple is asserted as the exact result-shape contract the guardrail and context ledger will consume.
- **SEC-002**: argument validation rejects unknown/missing/mistyped inputs at the boundary, before any handler runs.
- **FR-013 (/tools)**: listing and direct invocation work through the same membrane; malformed input and unknown tools fail explicitly at the REPL surface.

## Regression scope

Full offline suite (TP-001..TP-004 unchanged in expectations; /tools moves from the explicit-failure list to real behavior — the stub-guard list narrows again, an intended evolution of our own TP-001 test). Structural gates: import boundaries (registry imports only shared — the injection ruling keeps the mandated edge set true), docstring gate, language gate, secret scan.
