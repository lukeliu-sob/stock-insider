## Driver

DE-09 (INV-002 recall) is recorded as accepted residual risk (ADR-006 Amendment 12). An INV-002 miss carries no visible marker: the unverified marker covers numbers only, and 8 of the 16 sealed-battery misses that remain after the TP-033 fix contain no number. The owner asked for a fixed reliability notice shown after every answer.

## Change

- `src/stockinsider/agent/loop.py`: a constant `AGENT_NOTICE` ("Agent is a probability machine, which may make mistakes."). The normal answer path prints it on the progress channel directly after the post-check footer.
- Display only. The notice is not in the rendered answer, the session record, or the next turn's model input (tested below).
- No other exit prints it. The iteration cap, a provider error and an aborted session give no answer, so they show no notice. The footer format is unchanged.
- Placement is the author's choice: after each answer, on the progress channel, so the plain REPL and the terminal UI both show it. The owner can move it.

## Planned tests

File: `test/offline/test_tp034_fixed_notice.py`.

| Test | Verifies | Kind |
|---|---|---|
| `test_notice_follows_the_footer_of_an_answered_turn` | the notice is printed exactly once, on the line directly after the footer | positive |
| `test_notice_is_not_part_of_the_answer_or_the_session_record` | the notice is not in the rendered answer, the outcome text, or the stored session events | negative / adversarial |
| `test_notice_stays_out_of_the_next_turns_model_input` | no model call after the first answer carries the notice text | negative / adversarial |

Mutation check: printing the notice inside the answer text fails the second test; printing it before the footer fails the first.

## Regression scope

Full offline suite, ruff, mypy, every structural gate, and the AI-use log gate (AILOG-0081). The footer-dependent suites pass unchanged: `test_agent_loop.py`, `test_tui_session.py`, `test_tp020_partial_dates.py`, `test_tp023_verify_and_flag.py`.

## Fit-criteria mapping

REQ-SI-INV-002: a fixed notice appears after every answered turn, and it never enters the text that the INV-001 and INV-002 checks read, nor the record that replay and the next turn use.
