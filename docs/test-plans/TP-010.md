## Scope

1. **Fundamentals adapter** (`data/ingest/fundamentals.py`): one request
   per symbol against `https://eodhd.com/api/fundamentals/{symbol}`
   (income statement, balance sheet, cash flow — quarterly), strict
   schema validation (required fields per FR-002), transactional
   storage into `fundamentals` (statement rows keyed by period end);
   the vendor's `General`/`Highlights` sections persist as a profile
   row (new small table via **migration v3**: `symbol_profiles`).
   Cost accounting: one fundamentals fetch spends **10** budget units
   (the vendor's per-request call price), not 1.
2. **Sync track**: `fundamentals:{symbol}` — fetch on watch-add
   backfill and on sync when the newest stored quarter is older than
   the symbol's latest market bar by one quarter boundary (a cheap
   deterministic staleness rule; no calendar API).
3. **Coverage report** (FR-002 fit criterion): per watchlist symbol,
   the 8 most recent quarters × required fields (revenue, net income,
   total assets, shareholders equity, operating cash flow);
   completeness ratio computed and reported; symbols below 99%
   appear in an explicit coverage report — never silently omitted.
   Missing statements on the vendor side are recorded as explicit
   gaps (INV-003), not fabricated zeros.
4. **`data/compute` birth** (FR-006 static gate starts biting):
   pure functions only — `pct_change(a, b)`, `max_abs_daily_move(
   bars, window)`, `period_over_period(series)`. No market-data
   arithmetic anywhere else (the existing static gate now has
   something to guard).
5. **`info` command** (FR-005): fully deterministic — latest quote
   (close, adjusted close, date, exchange, currency), profile
   (name/sector/industry), key fundamentals of the latest quarter
   (revenue, net income, equity, operating cash flow — each with its
   period-end date), and recent significant moves via compute
   functions (largest |%| daily move of the trailing month; move vs
   20 sessions ago). Renders with providers unreachable (exit 0);
   every numeric carries a data date; missing sections render
   explicit unavailable lines.
6. **Registry tools** (first real numbers through the membrane):
   `market.quote` (READ; latest bar for a symbol) and
   `fundamentals.summary` (READ; latest quarter + coverage ratio) —
   INV-001 postcheck now sees real market numerics in snapshots.
7. **Live access reality (probed 2026-09-21)**: the fundamentals
   endpoint returns **403** on the current plan (All World) — the
   Fundamentals Data Feed is a separate package. **Development and
   tests use the vendor's demo symbols** (AAPL.US et al. expose all
   APIs without limitation) plus fixtures; production breadth for
   HK/US activates when the owner adds the package (a key-only
   change, zero code). The 403 handling is an explicit
   plan-not-covered failure message, never a silent empty result.

**Not in scope**: valuations/indicators beyond the display moves
(TP-013), news (TP-011), event scoring.

## Negative tests (mandatory, R7)

Malformed payload; missing required field (explicit gap, no
substitution); 403 plan-not-covered; unknown-symbol info; provider
down during info (still exit 0).

## Boundary cases (R8)

Coverage at exactly 99% vs one cell below (24/25 vs 23/25 of the
required grid); exactly 8 quarters stored vs 7 (coverage report
flags 7).

## Fit-criteria mapping

- **FR-002**: coverage-grid tests pin ≥8 quarters, required fields,
  explicit coverage report, zero silent omissions (403/missing
  statements surface as explicit gaps).
- **FR-005**: DB-only render tests; numeric-with-date assertion;
  provider-down exit 0.
- **FR-006 (birth)**: golden-value compute tests + the pre-existing
  static gate now guarding real compute code.
