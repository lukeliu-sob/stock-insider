## Driver

The offline suites pass, but a run against the owner's real store found defects the fixtures never reach:

1. **Primary HK rows demoted.** Migration v6 (`UPDATE symbols SET verified = 0 WHERE exchange NOT IN ('HK', 'US', 'INDX')`) also demoted the owner's three watchlist rows, which an early build stored with the exchange spelled `HKEX`. `watch list` shows `[unverified resolution]` on all three, and `verified_names` returns nothing for them, so the TP-025 stage-4 `official_name` is null in real use and the DE-16 name checks never run.
2. **Placeholder names count as verified names.** A direct-verified symbol (BD-017) is stored with `verified = 1` and the placeholder name `"<symbol> (name unverified - ...)"`. `verified_names` returns that placeholder as an official name, which contradicts its own docstring. The stage-4 tests seed the placeholder row with `verified = 0`, so they never reached this.
3. **Session subjects are never recorded (FR-012).** The REPL creates every session with no `subject_symbols` and nothing adds them, so `sessions --symbol` and the `session.list` tool never match a real session. The CLI listing also omits the last-active date that FR-012 names.
4. **A keyless sync spends budget.** `SyncService._execute` spends a call before the adapter checks for the EODHD key, so a run with no key reports `calls 4/20` although no request went out (INV-003: the report states something that did not happen).
5. **CLI details.** `info` does not show the exchange (FR-005 names it). A lowercase symbol (`0700.hk`) is not normalized. The REPL's `/watch remove` asks for confirmation before it checks that the symbol is on the watchlist.

## Scope

- `data/store/schema.py`: **migration v9.** A row whose canonical symbol ends in `.HK`, whose exchange is an HKEX spelling (`HKEX`, `SEHK`, `HKSE`), and whose name is not the direct-verification placeholder is set to exchange `HK` and `verified = 1`. This undoes v6's demotion of primary listings only: v6 meant secondary venues (ADR-005 Am2), and HKEX is the primary HK venue. Nothing else changes, and v6 is not edited (migrations are append-only).
- `data/store/__init__.py`: `verified_names` drops a placeholder name (`UNVERIFIED_NAME_MARKER`, the `"(name unverified"` text that `verify_symbol` writes).
- `agent/session.py`: `append_event` adds a canonical-shaped `symbol` argument of a `tool-call` event to the index row's `subject_symbols`, except for `session.*` tools, which look up the index rather than a security. Only the index row changes. `session.jsonl` stays append-only, and no event's shape changes. Sessions written before this change keep their recorded (empty) list, since the listing is index-only by FR-012's trade-off.
- `cli/app.py`: `sessions` prints last-active. `info`, `watch add` (on the direct path) and `watch remove` upper-case a symbol-shaped argument.
- `data/store/info.py`: the header line names the exchange from the symbol map, or says `exchange unknown`.
- `data/ingest/sync.py`, `market.py`, `fundamentals.py`: the key check runs before the budget spend. The item still fails with the same message, and the call count stays unchanged.
- `agent/repl.py`: `/watch remove` checks membership through `watchlist.list` before asking. `/report` and `/watch remove` upper-case a symbol-shaped argument.
- Not changed: `shared/`, `agent/registry.py`, `agent/guardrail*`, `prompts/`, and the REPL `/sessions` line format (pinned by the plain-REPL golden file).
