## Driver

Three small, independent, low-risk items from the debt-register remediation plan's "Phase 1" are bundled under one test plan (the TP-017 PR-1..3b precedent: one plan, several small changes):

- **DE-01** (evaluation debt, partial repayment): `requirements.yaml`'s PERF-001..003 hold `status: future` with provisional thresholds ("<5s", "<120s", "<10min") nobody has ever measured against; CI has no timing instrumentation anywhere. Setting a real threshold now would mean inventing a number, so this plan adds measurement only — the thresholds stay `TBD`/`future`.
- **DE-06** (guardrail debt): cross-file ID references (`DE-NN`, `TP-NNN`, `RM-NN`, `ADR-NNN`, `REQ-SI-*`) between `docs/architecture/adr/*.md`, `docs/ai-use-log.yaml`, `docs/req/requirements.yaml`, `docs/architecture/trace-matrix.md` and `architecture-blueprint.md` are human-maintained; no structural check verifies they resolve.
- **DE-10(d)** (guardrail debt, the one remaining sub-item of DE-10 after TP-024 repaid (a)-(c)): nothing in `prompts/identity.md` tells the model its own tool-call *arguments* (e.g. "k=10 requested") are not citable evidence, distinct from tool *results*, which the existing "Numbers come from tools" rule already covers.

## Fix

1. **DE-01**: add `time.perf_counter()` measurement, printed to stdout (not asserted against any threshold), to `test/offline/test_cli_info.py`, `test/offline/test_ingest_market.py`, and `test/live/test_eval_set.py` — the three files `requirements.yaml`/`trace-matrix.md` already name as the future "timing mode" targets. `requirements.yaml`'s PERF-001..003 text and status are unchanged.
2. **DE-06**: new `tools/checks/reference_lint.py`, same shape as `testplan_gate.py`/`aiuse_gate.py` (`CI_BASE_SHA`-gated in CI mode, PASS/FAIL with a clear message, runs unconditionally in local mode so it is exercised every run, not just in CI). It collects every `DE-\d+`, `TP-\d{3}[a-z]?`, `RM-\d+`, `ADR-\d{3}` and `REQ-SI-[A-Z]+-\d{3}` token cited anywhere under `docs/`, and fails if a cited token has no matching heading/entry in its home artifact (`### DE-NN` in `debt-register.md`, a `docs/test-plans/TP-NNN.md` file, `### RM-NN` in `review-memo.md`, `docs/architecture/adr/NNN-*.md`, or a registry entry in `requirements.yaml`).
3. **DE-10(d)**: one new bullet in `prompts/identity.md`'s `## Disciplines` list, immediately after "Numbers come from tools" (current lines 28-30): the model's own tool-call arguments are not citable evidence. Frontmatter `version: 6` -> `7`; a line added to the version-history HTML comment (lines 8-14), matching the file's own convention.
