## Scope

**Changes**: `shared/` package birth (safety-critical, ADR-004 charter): `language.py` (runtime English-policy helpers; CI artifact gate unchanged), `egress.py` (SEC-003 whitelist + fail-closed `validate_egress_url` with dynamic `extra_allowed` for resolved provider endpoints), `provenance.py` (GOV-005 authoritative stamp: field set, `ProvenanceStamp`, placeholder prefix, `validate_provenance`), `events.py` (FR-011 authoritative `EventKind` enum + `validate_event`, session-open provenance linkage). Adoption: `agent/session.py` imports the shared authority and validates stamps at creation (stricter than before, per GOV-005 fit). `docs/architecture/adr/004-shared-foundation.md`. Tests: `test/offline/test_language_policy.py` and `test/offline/test_egress.py` (both trace-matrix-named), plus persistence-suite extensions.

**Explicitly does not change**: tool I/O schemas (TP-005/ADR-005 — designed against the real registry consumer), the CI language gate, egress HTTP choke-point wiring (data-side TP), `agent/providers`/`repl` behavior (stamps already resolve via TP-003), registry/guardrail (later TPs), prompts.

## Negative tests (mandatory, R7)

Eleven negative/adversarial tests above. Headline intents: no CJK reaches runtime output paths unflagged; no non-whitelisted or non-HTTPS egress passes silently; no session exists with missing/blank/wrong-typed provenance (GOV-005 zero-tolerance at creation time); no unknown event shape enters session.jsonl validation tolerance.

## Boundary cases (R8, for threshold rules)

None — this change introduces no numeric thresholds. (Domain-suffix matching is exercised at its boundary: `data.api.eodhd.com` passes, `api.eodhd.com.evil.example` fails — the suffix-boundary adversarial pair.)

## Fit-criteria mapping

- **FR-014/GOV-001**: runtime helpers tested for the exact rejection classes the requirement names (English only; the symbol-map exception is the symbol layer's duty, stated in error text).
- **SEC-003**: fail-closed URL validation with S2 evidence (egress denials) — the choke point adopts this unchanged when the data side lands.
- **GOV-005**: stamp validation enforces zero missing fields at creation (fit criterion verbatim); roundtrip proves type↔record fidelity.
- **FR-011**: `validate_event` accepts every event shape this codebase has ever written (replayed from a real session tree) and rejects unknown kinds — the forward-only authority.

## Regression scope

Full offline suite (all TP-001..003 tests unchanged). Structural gates: import boundaries (shared imports nothing internal beyond itself; agent→shared edge now exercised), docstring gate on the new package, secret scan, language gate. The adoption change in `agent/session` is covered by the existing persistence suite plus the new negatives.
