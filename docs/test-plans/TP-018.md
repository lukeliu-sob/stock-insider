## PR-1 — P0 package: token flow + prelude validation + egress crash

| Finding | Fix |
|---|---|
| H3-① token relayed by the model is quarantined (digit-bearing hex) | the REPL renders the pending write AND its token directly via progress() chrome (never model output, never post-checked); the model's tool result no longer carries the token ("do not repeat"); token alphabet becomes 8 lowercase letters (defense in depth: no digits to extract) |
| H3-② confirmation shows no bound content | confirm echo renders tool + JSON arguments; usage hint printed when the token is issued |
| H3-④ confirmation outcome invisible to the model | the confirm path appends a `[harness] confirmed write executed: ...` user-message event, so `_history_messages` (user/assistant only) carries it; /report can no longer truthfully claim a confirmed add never happened |
| H3-⑤ tokens never expire | `run_turn` calls `confirmations.expire_turns(turn_no)` at turn start (max_age 3) |
| H3-⑥ "confirm"-prefixed questions swallowed | REPL dispatch requires the strict shape `confirm [a-z]{8}`; anything else is a normal conversational turn |
| H3-③ all search candidates verified=1 | resolver.record marks verified=1 only for PRIMARY_EXCHANGES (HK/US/INDX); secondary venues return verified=0 folded candidates |
| H1 residual (pre-tool text unvalidated) | per-iteration provider text accumulates as prelude; the post-check validates prelude + candidate as one string; the assistant-message event stores the full displayed text (screen == record) |
| new-4 egress crash (EgressViolationError escapes) | provider wraps EgressViolationError into ProviderError; `config set --chat-base-url/--embedding-base-url` validates at write time (EGRESS_EXTRA_HOSTS extends); REPL except broadened as defense in depth |
| new-8 regeneration recheck uses the turn pool only | the recheck pool becomes the session ledger (same as the primary check) |

`shared/egress.py`, `prompts/identity.md` (v6, token wording),
